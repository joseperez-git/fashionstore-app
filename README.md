# Fashion Store

Aplicación web tipo e-commerce desarrollada con Angular para el curso de JavaScript Avanzado.

## Descripción

Fashion Store es una tienda virtual de ropa que permite visualizar productos, ofertas y gestionar una simulación de inicio de sesión utilizando LocalStorage.

El proyecto fue desarrollado utilizando Angular, Bootstrap y JSON Server para el consumo dinámico de productos.

## Tecnologías utilizadas

- Angular
- TypeScript
- Bootstrap
- HTML
- CSS
- JSON Server
- LocalStorage
- Git y GitHub

## Funcionalidades

- Navbar reutilizable
- Footer reutilizable
- Página Home
- Página Productos
- Página Ofertas
- Página Tienda
- Página Contacto
- Página Mi Cuenta
- Login simulado
- Dashboard protegido
- Página 404 personalizada
- Consumo de API REST
- Routing en Angular
- Responsive Design
